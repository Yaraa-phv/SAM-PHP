# Student Attendance Management System (SAM-PHP)

A modern, user-friendly PHP web application for managing student attendance in a private school.

## Features
- Check and record student attendance
- Track permission requests (e.g., leave/absence)
- View attendance performance for any student
- Search students by name or ID (e.g., STU001)
- Responsive, modern UI with Bootstrap

## Tech Stack
- PHP (backend)
- MySQL (database)
- Bootstrap (frontend)

## Setup Instructions
1. Clone the repository.
2. Import the `database.sql` file into your MySQL server.
3. Configure database credentials in `config.php`.
4. Deploy the project to your PHP server (e.g., XAMPP, LAMP, etc.).

## Usage
- Access the web app via your browser.
- Use the navigation to manage attendance, permissions, and view reports.
